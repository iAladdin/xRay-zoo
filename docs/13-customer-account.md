# 用户中心与访问撤销

本地入口：`http://localhost:3100/account`。普通用户登录后自动进入；管理员仍默认进入 `/admin`，也可从后台右上角切换到自己的用户中心。

## 用户操作

- 我的订阅：当前套餐、已用/剩余流量、到期时间、自动续费状态、五区域节点状态。
- 复制订阅链接：在 Clash Meta / Mihomo 中从 URL 导入，后续更新可从同一有效链接取得。
- 下载 YAML 配置：保存 `xray-zoo.yaml`；复制 YAML 内容：用于客户端剪贴板导入。两者都通过登录会话读取本人的当前配置。
- 撤销访问（Revoke）：确认后旧链接立即失效，worker 向节点同步禁用该接入身份。已付套餐、流量额度、累计用量和到期时间保留。
- 生成新配置并启用：撤销同步完成且仍有有效服务期及剩余流量时可用。生成新链接并轮换 VLESS 身份；旧配置不会随恢复重新生效。所有设备都需要重新导入。
- 套餐与订单：查看可售套餐、本人最近 20 笔订单及测试付款状态，待支付订单可继续支付。
- 取消自动续费：独立确认操作，仅停止未来续费，不立即撤销当前访问。撤销访问不会自动取消续费。

配置沿用 tc split：AI 只使用 JP / SG / US，Telegram 只使用 HK / TW；对应区域不可用时不回落到其他地区。导出的链接和 YAML 都是访问凭证，不能公开分享。

## 权限与状态

所有 `/account/*` 接口要求登录，用户身份只从会话取得，不接受客户端指定其他用户。下载与公开 token 下载共享相同检查：有效服务期、未撤销、未暂停、剩余流量、权益同步完成。配置不缓存；只导出启用、控制就绪且检测在 120 秒内的节点。

`Subscription.revokedAt` 独立记录用户撤销意愿。后台定期对账、支付回调或管理员恢复不会自动清除此标记。管理员暂停优先，用户不能自行绕过。用户显式重新生成并成功同步后才清除该标记。

写操作使用期望版本、行锁与同步租约，冲突返回 409；撤销重复提交具有幂等性。状态变更与 outbox 同事务提交，并记录审计。前端每 5 秒更新账户，续费状态每 60 秒从 Stripe 查询。

重新生成时调用引擎的身份撤销 API，保留同一个计量用户与累计计数。旧 UUID 密文保留至新身份完整同步，任务重试通过引擎回读识别已完成的轮换，避免故障恢复时再次轮换。原服务期计量基线不重置。

## 验证与运行

```sh
pnpm db:generate
pnpm db:migrate
pnpm test:account
# 当前宿主使用系统 TUN，实际节点探测显式绑定物理网卡：
PROBE_INTERFACE=en0 pnpm test:account
```

测试创建两个独立临时用户，检查未登录拒绝、用户隔离、非法输入、管理员暂停不可绕过、撤销幂等、旧链接失效、原额度与到期日保留、引擎轮换中断后的重试恢复、撤销期间续费更新服务期但不恢复访问。设置 `PROBE_INTERFACE` 后还用真实 Mihomo 客户端验证旧 YAML 被拒绝、新 YAML 可连接，以及重新生成后旧 YAML 仍被拒绝。默认清理测试账本并禁用引擎测试身份；`KEEP_TEST_ACCOUNT=1` 可临时保留一个测试账户供 UI 验证，凭证仅保存在忽略的 `.local/customer-ui.json`。

2026-11-18 已完成上述真实节点验证。浏览器验证包含普通用户登录跳转、复制链接/配置、YAML 下载、撤销与重新生成、本人订单和使用指南。

节点禁用为异步传播，离线节点会在重连后收到变更。已验证旧配置不能建立新连接，未测量所有既有长连接的清退时间。用量为最近一次引擎采集值，仍无按日流量账本。本版本只在本机运行并使用 Stripe Sandbox，未发布正式收款或公网 SaaS。
